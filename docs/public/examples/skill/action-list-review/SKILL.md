# Pemeriksaan daftar tindakan

1. Pastikan dulu file input dan file output yang ditunjuk pengguna; bila belum ditunjuk, tanyakan
   lebih dulu, jangan menebak sendiri.
2. Baca hanya input yang ditentukan; jangan mengubah file aslinya.
3. Setiap butir tindakan harus memuat: pokok pekerjaan, penanggung jawab, tenggat, serta batasan atau
   syarat verifikasi.
4. Informasi yang tidak ada di sumber ditulis "tidak dijelaskan di sumber"; jangan menambahkan nama
   atau tanggal sendiri.
5. Setelah menulis, baca ulang input dan output, lalu periksa satu per satu kelalaian, duplikasi, dan
   dugaan yang tidak berdasar.
6. Di akhir, laporkan path yang dibaca, path yang ditulis, jumlah butir tindakan, dan hal yang masih
   belum pasti.
