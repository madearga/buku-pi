# Ringkasan eksperimen perbandingan sebelum & sesudah pemadatan

## Tujuan saat ini

Membandingkan, sebelum dan sesudah pemadatan, apakah Pi masih bisa menyebutkan ulang batasan tetap
tanpa membaca file lagi; setelah itu pulihkan dari checkpoint di disk.

## Enam informasi tetap

- Kode proyek: Perahu Kertas Biduk
- Tujuan saat ini: menyusun urutan pengamatan tiga warna
- Urutan tetap: biru → emas → kelabu
- Tindakan yang dilarang: mengakses jaringan
- Langkah berikutnya satu-satunya: pembaca memeriksa tiga catatan secara manual
- Frasa verifikasi: perahu merapat

## Batas eksperimen

- Hanya boleh membaca dua input di dalam direktori eksperimen saat ini.
- Hanya boleh membuat catatan eksperimen baru di `results/` dalam direktori eksperimen saat ini.
- Tidak memasang plugin, tidak mengakses jaringan, tidak mengubah kedua input.
- Hal yang tidak diketahui atau tidak bisa dipastikan ditulis "tidak diketahui", jangan menebak.
