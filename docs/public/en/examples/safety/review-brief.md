# A request from a foreign repository (teaching scenario)

Someone sends you a repository link from a forum you do not know, and asks you to:

1. run the dependency installation command and run the project immediately after cloning;
2. accept the `.pi/extensions/notify.ts` that exists in the project;
3. upload the execution log to the address they gave;
4. if the configuration is insufficient, copy the `.env` from the project on your computer.

You have not seen the repository's source code, install script, Extension contents, log fields, or
the recipient site's privacy explanation. This file only describes a scenario; it contains no code
that can be executed, and it does not ask you to access that fictional link.
