# Poin penting pembaruan Pi 1.0.0

Pi 1.0.0 dirilis pada **1 Oktober 2026**. Halaman ini disusun berdasarkan Changelog resmi, dengan tanggal verifikasi **2026-10-02**. Perubahan rinci berbahasa Inggris yang lengkap tersimpan di [arsip versi](/releases/#release-v1-0-0); di sini dijelaskan perubahan yang paling mungkin Anda temui dalam pemakaian sehari-hari.

[Artikel rilis “Pi 1.0”](/translations/pi-1-0) membahas hasil keseluruhan ketika produk mencapai 1.0; sebagian kemampuannya sudah ditambahkan secara bertahap sebelumnya. Tabel di bawah mengacu pada **perubahan yang tercatat pada changelog versi 1.0.0**, jadi tidak semua kemampuan yang disebut dalam pengumuman rilis dihitung sebagai hal baru pada hari itu.

## Perubahan yang perlu diperhatikan

| Perubahan | Dampaknya bagi pengguna |
| --- | --- |
| Antarmuka terminal layar penuh sebagai bawaan | Setelah dijalankan, Pi memakai seluruh terminal; jika Anda ingin riwayat gulir terminal biasa tetap tersedia, kembali ke mode `regular` |
| Prompt Codemode lebih ringkas | Pada contoh resmi, permintaan GPT-5.6 dengan Codemode aktif sebagai tool bawaan turun dari sekitar 5.300 menjadi 3.300 token; ini tidak berarti total biaya semua sesi turun sekitar 40% |
| Codemode dapat membuat gambar | Skrip dapat memanggil `models.generateImages()` memakai kredensial sesi saat itu; gambar yang dihasilkan dilampirkan ke hasil oleh `image()`, dan biayanya dihitung ke sesi |
| Pintu masuk login Radius | `/login` menyediakan login Radius, dan setelah masuk Anda dapat mengonfigurasi server MCP yang bersangkutan |
| Login Anthropic lewat kode verifikasi | Jika browser berada di mesin lain, tersedia pilihan login dengan menyalin kode verifikasi |
| Pesan kesalahan tool yang lebih jelas | Kesalahan penulisan nama tool, nama model, atau format argumen memberi petunjuk pemulihan yang lebih spesifik |
| Informasi startup yang lebih ringkas | `quietStartup: "header"` mempertahankan versi dan petunjuk tombol, dan menyembunyikan daftar sumber daya startup lainnya |

Pembuatan gambar di Codemode hanya berlaku untuk model gambar yang sesuai dan penyedia yang sudah dikonfigurasi; ini tidak berarti semua model obrolan biasa dapat menghasilkan gambar. Angka pada tabel di atas berasal dari konfigurasi yang ditentukan resmi dan bukan hasil uji performa mandiri Buku Pi.

## Perbaikan login, sesi, dan antarmuka

MCP OAuth memperoleh beberapa perbaikan pada versi ini: memvalidasi `iss` pada respons otorisasi agar tidak menerima respons dari server otorisasi yang salah; menangani kolom opsional yang kosong; mempertahankan cakupan izin yang sudah ada ketika menambahkan izin; serta menyimpan kredensial per nama server dan per URL, sehingga konfigurasi berbeda dengan URL sama dapat memakai akun berbeda. Kredensial lama yang hanya disimpan per URL akan dipindahkan ke server pertama yang memakainya.

Saat memulihkan sesi dan menjalankan `/reload`, tool MCP tertunda yang sudah dimuat oleh `tool_search` seharusnya tidak lagi hilang karena urutan reconnect server dan pemulihan tool. Perbaikan lain mencakup flag startup Apple Terminal, penyorotan pilihan pada mode layar penuh, pelengkapan perintah, serta pemakaian memori untuk pesan yang panjang.

Selain itu, **mengirim `--provider` tanpa `--model` kini menampilkan kesalahan dengan jelas**, tidak lagi diam-diam memakai model bawaan penyedia lain. Jika skrip startup Anda sudah ditulis seperti itu, tambahkan model yang sesuai.

## Bagaimana memeriksanya setelah peningkatan?

Catat dulu `pi --version` saat ini, lalu tingkatkan versi lewat jalur yang sama dengan cara instalasi Anda semula seperti dijelaskan di [Siklus hidup setelah instalasi](/guide/lifecycle-management). Instalasi yang sudah ada dapat memakai perintah `pi update` dari CLI resmi; instalasi npm memerlukan Node.js 22.19.0 atau lebih baru.

Setelah meningkatkan versi, jalankan di terminal biasa:

```bash
pi --version
```

Jika versinya cocok dengan versi pada halaman ini, hasilnya menampilkan `1.0.0`; jika Anda langsung memperbarui ke versi terbaru, hasilnya bisa lebih tinggi dan Anda perlu memeriksa changelog yang sesuai. Setelah masuk ke Pi, pastikan model yang biasa Anda pakai masih menjawab dengan normal, Ekstensi yang umum dipakai masih dapat dimuat, dan server MCP yang dibutuhkan dapat terhubung.

Jika belum terbiasa dengan layar penuh sebagai bawaan, Anda dapat menjalankan sementara seperti ini:

```bash
pi --tui-mode regular
```

Anda juga dapat mengatur `tuiMode` menjadi `"regular"` pada pengaturan yang sudah ada. Jangan menimpa seluruh file pengaturan hanya untuk menambahkan satu kolom ini.

Jika Anda memelihara skrip Codemode, penulisan lama yang memakai `typeof tools.name` untuk mendeteksi keberadaan tool perlu diubah menjadi `"name" in tools`.

## Pi Durable dirilis bersamaan, tetapi posisinya berbeda

Pi Durable adalah kerangka kerja aplikasi eksperimental yang dirilis pada waktu yang sama, untuk aplikasi Agent yang berjalan lama, pulih secara persisten, dan menjalankan banyak sesi. Ia tidak menggantikan asisten pemrograman Pi sehari-hari, dan tidak berarti bahwa setelah meningkatkan versi ke 1.0.0, tugas yang sudah ada otomatis memperoleh mekanisme pemulihan yang sama.

Untuk memahaminya lebih jauh, mulailah dari [Panduan pengantar Pi Durable](/guide/pi-durable), lalu baca [terjemahan lengkap resminya](/translations/pi-durable).
