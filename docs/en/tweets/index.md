# Tweet Learning Table of Contents

These tweets were originally published separately in chronological order. Now I have rearranged 98 original tweets about Pi from 11 August to 8 September 2026 into a single learning route, from beginner to long-term work.

There is no long list here organized by date. Each original tweet goes into only the one stage that fits it best, and within that stage the tweets are ordered chronologically from earliest to latest. Readers can study in order, and at the same time see how my understanding developed.

## Six Stages

| Order | Stage | Number of tweets | After you finish |
| --- | --- | ---: | --- |
| 01 | [Getting to know Pi out of curiosity](/en/tweets/01-meet-pi) | 27 | First understand what Pi is, why it stays simple, and how the Agent Harness affects the real experience. |
| 02 | [Finish your first task first](/en/tweets/02-first-tasks) | 25 | Learn about model selection, beginner tips, and the basic interface, then return to a small task you can verify on your own. |
| 03 | [Understanding Sessions and context](/en/tweets/03-sessions-context) | 7 | Understand the relationship between the session tree, long-term memory, compaction, tokens, and prompt cache. |

## Suggested Reading Order

The first time through, read the explanation at the start of each stage, then pick two or three original tweets closest to your current problem. If you want to understand the whole learning process, read in order from 01 to 06.

Models, versions, prices, and product statuses inside the tweets can change. Dates are part of how to understand them. For anything related to installation and hands-on practice, go back to the [main learning path](/en/guide/before-install) for tutorials that have been re-verified.

Extensions, Packages, Skills, and standalone clients scattered across many tweets have been tidied up separately into [plugin recommendations and a map of options](/en/plugins/). The recommendation page checks current sources and risks; this table of contents still keeps the original assessment from that time.

Learning principles that came up repeatedly and have not been overturned after later practice have been filtered into [ten judgments left from 98 tweets](/en/guide/lasting-principles). That page holds the Buku Pi's current conclusions; here we still keep the original wording, publication dates, and shifts in understanding, so the two do not overwrite each other.
