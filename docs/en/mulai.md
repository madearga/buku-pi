# Learning Map

This page summarises the whole path so you can see the big picture before starting, or come back
here when you lose your way. Every lesson linked below has already been verified.

## How to use this map

1. If you have never opened Pi, do [First success in 30 minutes](/en/guide/start-here) first.
2. Work through modules one to five in order; each module has its own completion sign.
3. Keep this page handy so you can check your position whenever you get lost halfway.

The estimates below are rough figures for a single pass; download speed, browser authorisation, and account status can make them longer.

| Stage | Content | Estimate | Completion sign |
| --- | --- | --- | --- |
| Opening & prologue | 3 lessons + 1 timeline | 30–45 minutes | You know why the path is arranged this way |
| Module one | 4 lessons (+1 Windows route) | 60–90 minutes | Pi answers inside its own practice directory |
| Module two | 3 lessons | 60–90 minutes | You check the input, output, and task requirements yourself |
| Module three | 2 lessons | 45–60 minutes | Key results are saved before the context fills up |
| Module four | 3 lessons | 90–120 minutes | The new capability is proven to actually work |
| Module five | 2 lessons | 60–90 minutes | There is a checkpoint, a recovery path, and permission limits |
