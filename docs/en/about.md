# About This Edition

This English edition, together with the Indonesian edition at the site root, is maintained by
**Argakuka**. Its content was reworked from the Mandarin edition of the BUKU PI project, then
translated and adapted for Indonesian readers; the page structure, learning path, and design are
preserved.

## Where the Content Comes From

At first it was pure curiosity: Pi looks so compact, so why can it become the starting point for so many workflows? The original author began by doing the first task, leaving behind learning notes, then reading the source code, trying to write an Extension, and constantly revising early assessments.

The more notes accumulated, the clearer it became that beginners need more than a list of features; they need a path that carries them from the first task to building their own workflow, with a clear way to check the result at every step. That is the origin of the Buku Pi. Personal thoughts and experiments that are still changing live in [Learning notes](/en/journey/); only content that has been re-verified and works when followed step by step makes it onto the main path.

## How the Quality Is Kept

Rather than hearing an Agent say the task is done, this edition cares more about whether the result runs, can be reproduced, and can be checked independently. That is why every page follows the flow “Scenario → Concept → Practice → Verification”; when an old assessment turns out to be inaccurate, the page is corrected.

## Source & Reporting

The book is developed in the open. The code, the change history, and the place to report problems are
available in this project's repository; translation issues can be reported through the same channel.
