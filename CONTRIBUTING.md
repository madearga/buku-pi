# Panduan Kontribusi

Terima kasih sudah membantu merapikan Buku Pi edisi Bahasa Indonesia. Laporan pembaca tentang
satu langkah yang tidak bisa diikuti sama berharganya dengan perbaikan kode.

## Melaporkan masalah

Sertakan: halaman (URL), langkah yang dijalankan persis, hasil yang diharapkan, hasil yang muncul,
versi Pi (`pi --version`), sistem operasi, dan terminal yang dipakai. Bila menyangkut berkas contoh,
sebutkan nama berkasnya.

## Mengusulkan perbaikan

1. Untuk perubahan kecil (salah tulis, tautan mati, kalimat kurang jelas), kirim pull request langsung.
2. Untuk perubahan alur belajar atau struktur bab, jelaskan dulu alasannya di issue sebelum menulis.
3. Satu pull request sebaiknya menangani satu hal.

## Standar

- Tulis dalam Bahasa Indonesia yang tenang dan instruktif; gunakan "Anda".
- Ikuti `.translation/GLOSSARY.md` dan gunakan "file" (bukan "berkas").
- Jangan mengubah perintah, flag, atau path di blok kode tanpa menguji ulang langkahnya.
- Setiap pelajaran harus tetap punya cara verifikasi mandiri; jangan jadikan klaim agent sebagai bukti.
- Jalankan `npm run check` sebelum mengirim pull request.
